# Shiksha Saathi: Voice-Enabled AI Teaching Assistant

An interactive AI-powered classroom assistant optimized for Indian K-12 school curriculum delivery, supporting multilingual inputs, localized topic tracking, and automated classroom quiz timers.

## Local Setup
1. Clone the repository.
2. Install requirements: `pip install -r requirements.txt`
3. Run the application: `python app.py`
